# Pluginsisland

ClassIsland 插件管理增强插件（id: `xinxia.pluginsisland`）。

## 功能

- **「插件管理」导航分组**：在设置窗口左侧导航树中新增一个可折叠的「插件管理」父节点，下含：
  - **「已装插件」页**：每个已安装插件一张可折叠卡片，含图标、名称、版本、作者、加载状态，以及启用 / 停用开关、卸载 / 取消卸载，「从本地安装 .cipx」按钮与拖放安装
  - **各插件自身注册的设置页**：自动折叠归入本分组之下，不再散落于导航树顶层（插件在启动后注册的页面亦会被归组）
- **双击 .cipx 安装**：在「插件管理」页开启「注册 .cipx 文件关联」后，双击 .cipx 即可快速安装：
  - ClassIsland 运行中：弹出确认对话框，确认后重启并安装；取消则下次启动时自动安装
  - ClassIsland 未运行：插件包暂存至缓存目录并启动 ClassIsland，启动时自动安装

## 说明

- 文件关联仅写入当前用户注册表（HKCU），无需管理员权限；卸载本插件前请先在设置页关闭文件关联（卸载按钮会先自动注销）。
- 双击安装依赖插件自带的 `Pluginsisland.Helper.exe`，若被安全软件拦截请放行（无网络、无自启，仅本地操作）。
- 若本插件被禁用，双击 .cipx 仍会暂存并拉起 ClassIsland（启动即装），属预期降级行为。
